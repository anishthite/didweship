tiktok-days-by-slug.json stores day counts; runtime has no provider credentials.
Open Qs
1: add APIFY_TOKEN before the scheduled refresh can run.

Algorithm

  1. Read roster entries with tiktokLogin.
  2. Request up to 100 recent posts per run from the Apify actor.
  3. Deduplicate post IDs; bucket uploadedAt in NERV_TZ.
  4. Replace cached counts from the earliest returned day forward; retain older history.
